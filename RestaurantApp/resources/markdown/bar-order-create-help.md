# New Bar Order

This page is for walk-up bar service — guests at the bar who aren't sitting at a table. Use it to assemble an order, set quantities, add notes, and send to the bar queue.

## What's different from table orders?

Bar orders don't have a table assignment. The kitchen/bar staff see them in the bar queue with a *walk-up* tag instead of a table number. Otherwise the workflow is identical to table orders.

## Searching the Menu

The **search box** at the top filters drinks live as you type. Matches name or description.

- Type a drink name partially — "neg" finds "Negroni".
- Clear the search to see the full menu again.

Only items marked **Available at the bar** on the Dishes page appear here. If a drink is missing, edit that dish and tick the bar flag.

## The Drink Grid

Each card shows:
- **Photo** (or a default glass icon)
- **Name** and **price**
- **Description** (if entered)
- **Allergen icons** — hover for names
- A **+** button on the card to add to the order

### Out of Stock cards
- The card is dimmed with a black "Out of stock" badge.
- Clicking the card opens a panel showing **which ingredient** is out — useful for explaining to the guest.
- You cannot add an out-of-stock drink to the order.

### Quantity badge
A small badge appears on a card once it's in the cart, showing how many are queued.

## Adding a Drink

1. Click the **+** on a card to open the add modal.
2. See the help icon inside that modal for quantity + notes guidance.
3. Click **Add to Order**. The drink joins the cart at the bottom of the screen.

## The Order Cart

A fixed bar appears at the bottom of the screen as soon as you add a drink. It shows:
- Total item count
- Running total in €
- **Send to Bar** button

Click items in the cart to edit quantity, remove, or update notes.

## Sending to the Bar

When you have everything the guest wants:

1. Confirm the cart total with the guest.
2. Take payment (or note open-tab if your venue allows).
3. Click **Send to Bar**.

The order disappears from this screen and appears in the bar staff's queue (Orders page → Bar mode).

## Workflows

| I want to... | How |
| --- | --- |
| Walk-up order: one beer | Click + on the beer card, set qty 1, Add, Send |
| Big round | + each drink, set qty per drink, send all at once |
| Drink with note | + on the card, write the note, Add |
| Replace one drink in a queued order | Cancel + remake (orders can't be edited after Send) |

## Tips

- **Lock in the drinks before notes.** Get the guest to commit to what they want; *then* type any modifiers (ice, garnish, no-sugar).
- **Tell guests immediately if something is out of stock.** The card shows the blocking ingredient — share that so they can pick something compatible.
- **Send orders in batches** for big groups rather than one at a time — bartenders prefer building rounds together.
- **Take payment before Send** if your venue is cash-up-front for the bar — once sent, the order is locked.
