# New Bar Order

This page is for walk-up bar service — guests at the bar who aren't sitting at a table. Use it to assemble an order, set quantities, add notes, and send it to the bar queue.

## What's different from table orders?

Bar orders don't have a table assignment. Bar staff see them in the bar queue without a table number. Otherwise the workflow is the same.

## Searching the Menu

The **search box** at the top filters drinks live as you type. Matches name or description.

- Type a drink name partially — "neg" finds "Negroni".
- Clear the search to see the full menu again.

Only items marked **Available at the bar** on the Dishes page appear here. If a drink is missing, edit that dish and tick the bar flag.

## The Drink Grid

Each card shows:
- **Photo** (or a default glass icon if no photo has been uploaded)
- **Name** and **price**
- **Description** (if entered)
- **Allergen icons** — hover for names
- A **+** button to add to the order

### Out of Stock cards
- The card is dimmed with a black "Out of stock" badge.
- Clicking the card opens a panel showing **which ingredient** is out — useful for explaining to the guest.
- You cannot add an out-of-stock drink to the order.

### Quantity badge
A small badge appears on a card once it is in the order, showing how many are queued.

## Adding a Drink

1. Click the **+** on a card to open the add pop-up.
2. See the help icon inside that pop-up for quantity + notes guidance.
3. Click **Add to Order**. The drink joins the order and the badge on the card updates.

## The Order Bar

A bar appears at the bottom of the screen as soon as you add a drink. It shows the number of drinks and the running total in €.

Click **Review Order** to open the full order screen where you can:
- Adjust quantities with the **+** / **−** buttons
- Remove a drink with the **×** button
- Choose the payment method

## Review Screen & Payment

Before placing, you choose how the guest is paying:

- **Pay at Bar** — The guest pays at the counter now. You can also use **Print Ticket** or **Display Ticket** to show the order total to the guest before payment.
- **Room Number** — Enter the guest's hotel room number to charge the order to their room.

Once the payment method is set, click **Place Order** to send the order to the bar queue. The order disappears from this screen and appears on the Orders page under Bar.

## Workflows

| I want to... | How |
| --- | --- |
| Walk-up order: one beer | Click + on the beer card → set qty 1 → Add to Order → Review Order → Place Order |
| Big round | + each drink, set qty per drink, Review Order, Place Order |
| Drink with a note | + on the card → write the note → Add to Order |
| Hotel guest charging to room | Review Order → select Room Number → enter room → Place Order |
| Replace one drink in a queued order | Orders can't be edited after placement — cancel and remake |

## Tips

- **Lock in the drinks before notes.** Get the guest to commit to what they want first; *then* add any modifiers (ice, garnish, no sugar).
- **Tell guests immediately if something is out of stock.** The card shows which ingredient is blocking it — share that so they can choose an alternative.
- **Send orders in batches** for big groups rather than one at a time — bartenders prefer building rounds together.
- **Use Print Ticket or Display Ticket** to show the guest their total before they pay — avoids disputes about the price.
