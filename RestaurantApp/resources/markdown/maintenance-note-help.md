# Task Notes

Notes are the audit trail of a maintenance task. They are how the team communicates progress, blockers, and resolutions without losing context across shifts.

Open this sheet by clicking the notes cell on any task row. The sheet shows the task it's attached to in the subtitle.

## What to Write

Each note should be:
- **A short factual update.** Not a journal entry. One or two sentences.
- **Time-bound.** Past tense for what you did; present for what's blocking.
- **Action-shaped.** Mention what's next if known.

### Examples
- "Inspected, fixture is fine — bulb itself dead. Replaced. Test passed."
- "Driver burned out. Ordered part XYZ-123 from Supplier A, ETA Friday."
- "Tried reseating, no fix. Escalating to electrician — left voicemail."

## How Notes Work

Each task has one notes field. When you open the notes area and save, you are updating that field — previous content is replaced by whatever you type.

This means notes work best as a **running summary** that you keep up to date, rather than a back-and-forth thread. Write the current situation clearly each time you save.

## Author & Timestamp

Each save records:
- Who wrote the note (your account)
- When it was saved

This is visible to others looking at the task — assume notes are not private.

## Best Practices

- **Don't blame in notes.** They're a public record; keep them factual.
- **Mention part numbers** when ordering — saves the next person ordering the wrong thing.
- **Note any health/safety implications.** "Tile lifted, trip hazard" must be visible at a glance.
- **Update notes when status changes.** Going *On Hold*? The note should say what's blocking.
- **Close notes loop.** When you mark a task Completed, add a final note describing the actual fix — the next time the same thing breaks, this saves the team an investigation.

## Saving

- Click **Save** at the bottom.
- The sheet closes; the task row updates with the latest note preview and count.
- The note becomes searchable from the main list's search bar immediately.

## Tips

- **Write notes for strangers.** The next reader may be a new hire who has never seen this fixture before.
- **Skip pleasantries.** "Replaced part" is fine; "I went over and after a while I think I replaced the part" wastes the reader's time.
- **One note per real update.** Don't pad with "no change yet" updates — silence is acceptable in this system.
