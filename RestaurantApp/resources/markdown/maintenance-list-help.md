# Maintenance Task List

This is the work queue for the maintenance team. Every reported problem and follow-up job — leaky taps, broken table legs, flickering lights — lives here as a task with status, assignee, and notes.

## Searching & Filtering

### Search bar
Type any text and click **Search**. Matches against:
- Task title
- Notes added by staff
- Name of the assigned person

Click **Clear filters** to reset everything (search + quick filters + status).

### Quick filters
- **All** — Every task
- **My Tasks** — Only tasks assigned to *you*
- **Unassigned** — Tasks that still need an owner

### Status filter
Tick one or more status checkboxes to narrow the list:
- **Pending** — Reported, not started
- **In Progress** — Someone is working on it
- **Completed** — Finished
- **On Hold** — Blocked or waiting on a part

Filters combine: e.g. *My Tasks + In Progress* shows your active work.

## Reading a Row

| Column | What it shows |
| --- | --- |
| **Title** | Short name of the problem |
| **Status** | Coloured badge — click to advance |
| **Assignee** | Who owns it. Click to reassign. |
| **Notes** | Latest note + count. Click to view all / add one. |
| **Created** | When the task was opened |
| **Actions** | Edit / delete (permission-gated) |

## Creating a Task

Click **Add Task** in the page header. See the help icon inside the create sheet for field-by-field guidance.

## Working a Task

Two main interactions:

1. **Status cell** — Click to cycle through Pending → In Progress → Completed (or open a picker for On Hold).
2. **Notes cell** — Opens the notes sheet to add progress updates, photos, or parts ordered.

Both update the audit trail with timestamp + author.

## Common Workflows

### Starting your shift
1. Quick filter → **Unassigned**.
2. Pick tasks you can do; click the assignee cell to assign yourself.
3. Switch to **My Tasks** to focus.

### Reporting progress
- Click the task's notes count to open the notes sheet.
- Add a short update ("Replaced bulb, still flickering — ordering driver").
- Save.

### Blocked on a part
- Open notes; describe what's blocking.
- Open status; pick **On Hold** with a reason.

### Closing a job
- Verify the fix actually works.
- Open status → **Completed**.
- Optionally add a final note describing the resolution.

## Tips

- **Update status promptly.** Coworkers rely on it to know whether to pick up a job.
- **Don't claim too many at once.** Filter by *My Tasks + In Progress* before claiming more.
- **Write notes liberally.** Future-you (or the next shift) will thank you for the breadcrumbs.
- **Mark Completed only when verified.** Re-opening a "Completed" task is more disruptive than leaving it In Progress.
