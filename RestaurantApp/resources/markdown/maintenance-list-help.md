# Maintenance Task List

This is the work queue for the maintenance team. Every reported problem and follow-up job — leaky taps, broken table legs, flickering lights — lives here as a task with status, assignee, and notes.

## Searching & Filtering

### Search bar
Type any text to filter the list. Matches against:
- Task title
- Notes on the task
- Name of the assigned person

### Quick filters
- **All** — Every task
- **My Tasks** — Only tasks assigned to *you*
- **Unassigned** — Tasks that still need an owner

### Status filter
Tick one or more status checkboxes to narrow the list:
- **Unassigned** — Reported, not yet given to anyone
- **Assigned** — Given to someone, not yet started
- **In Progress** — Being actively worked on
- **Done** — Finished and verified

Filters combine: e.g. *My Tasks + In Progress* shows your active work.

## Reading a Row

| Column | What it shows |
| --- | --- |
| **Title** | Short name of the problem |
| **Status** | Coloured badge showing where the task stands |
| **Assignee** | Who owns it |
| **Notes** | A preview of the latest note |
| **Created** | When the task was opened |
| **Actions** | Edit / delete (permission-gated) |

## Creating a Task

Click **Add Task** in the page header. See the help icon inside the create sheet for field-by-field guidance.

## Working a Task

Once a task is assigned to you, use the **status buttons** on the task row to move it forward:

- **Assigned → In Progress** — When you start working on it.
- **In Progress → Done** — When the job is finished and verified.

Add notes at any time by clicking the notes area on the task row.

## Common Workflows

### Starting your shift
1. Quick filter → **Unassigned**.
2. Pick tasks you can handle; use the assignee field to assign yourself.
3. Switch to **My Tasks** to focus on your work.

### Reporting progress
- Click the notes area on the task row.
- Add a short update (e.g. "Replaced bulb, still flickering — ordering driver").
- Save.

### Closing a job
- Verify the fix actually works.
- Click the status button → **Done**.
- Add a final note describing what the actual fix was — saves time if the same problem comes back.

## Tips

- **Update status promptly.** Coworkers rely on it to know whether to pick up a job.
- **Don't claim too many at once.** Filter by *My Tasks + In Progress* before taking on more.
- **Write notes freely.** Future-you (or the next shift) will thank you for the detail.
- **Mark Done only when verified.** Re-opening a finished task is more disruptive than leaving it In Progress a little longer.
