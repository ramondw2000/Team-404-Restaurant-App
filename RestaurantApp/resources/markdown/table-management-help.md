# Table Management

The Table Management page lets you view and manage the restaurant floor plan, monitor table status in real time, take reservations, and edit the layout.

## Viewing the Floor Plan

- Use the **floor plan switcher** in the top-left corner to change between floor plans (e.g. Main Hall, Terrace).
- Each table shows its current status by color:
  - **Green** — Available
  - **Blue** — Reserved
  - **Red** — Occupied
  - **Gray** — Out of service
- Hover a table to see its name and seat count.

## Previewing Availability

- Use the **datetime picker** in the top-right corner to preview which tables will be free at a specific date and time.
- When a preview time is active, the picker turns amber and an amber banner appears at the top of the floor plan.
- Click the **X** next to the picker to clear the preview and return to live status.

## Searching & Filtering Tables

- Type in the **search box** to filter tables by name.
- Use the **seat count filter** to show only tables with a minimum number of seats.
- Toggle **status filters** to hide or show tables by their current state.

## Creating a Reservation

1. Click an available (green) table on the floor plan.
2. A reservation sheet opens on the right.
3. Fill in guest name, party size, date, time, and any notes.
4. Click **Save** to confirm the reservation.

## Editing Table Status

- Click a table to open its details sheet.
- Use the status buttons to manually mark a table as Occupied, Reserved, or Out of service.
- Changes apply immediately and are visible to all staff.

## Edit Mode

Edit Mode lets you reshape the floor plan itself.

- Click the **Edit** button in the top-right to enter Edit Mode.
- Drag tables to reposition them.
- Toggle **Snap to elements** for aligned placement.
- Keyboard shortcuts (Edit Mode only):
  - `Ctrl + C` — Copy selected table
  - `Ctrl + V` — Paste copied table
  - `Delete` — Remove selected table
  - `Shift` — Temporarily toggle snap
- Click **Done** to leave Edit Mode and save the layout.

## Managing Floor Plans

> Requires the *Manage Floor Plans* permission.

- Click the **+** icon next to the floor plan switcher to create a new floor plan.
- Rename or delete floor plans from the floor plan settings panel.
- Deleting a floor plan also removes its tables — confirm carefully.

## Tips & Shortcuts

- Hover any icon for a tooltip describing its action.
- The page auto-refreshes table status every few seconds — no need to reload.
- If a table appears stuck in the wrong state, refresh the page or check the reservation feed.
- Use the datetime preview before walking a guest to a table to confirm it stays free for their stay.
